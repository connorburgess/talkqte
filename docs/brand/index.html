How a live session starts and stops

Nothing leaves your Mac when you press Start live session. You approve each session before anything is sent, and Stop ends capture and sending immediately.

Per-session approval sequence
  1. Start live session opens the floating dock and starts local capture only. Audio captured before approval is discarded.
