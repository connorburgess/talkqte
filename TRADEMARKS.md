# TalkQTE name and logo

The [project license](LICENSE) covers the software. It does not grant trademark rights in the project's name or logo. This guide explains how Connor Burgess, the project steward, asks others to use them. It does not add restrictions to or replace the license text, and it does not limit uses that trademark law already allows.

## What this covers

- The name "TalkQTE".
- The TalkQTE logo and app icons, including [`public/mark.svg`](public/mark.svg) and the files in [`src-tauri/icons`](src-tauri/icons).

Connor Burgess claims these as unregistered marks identifying this project. No trademark registration is claimed.

This guide is about using the name and logo to identify software, not about copyright in the image files. Copies of those files published earlier under Apache-2.0 keep that license's copyright permissions, as described in the [licensing guide](LICENSING.md#previously-published-apache-20-material). Apache-2.0 section 6 likewise grants no permission to use the licensor's names or marks beyond describing the origin of the work.

## Uses that need no permission

- Referring to TalkQTE by name to describe it, review it, write about it, or link to it.
- Stating truthfully that your software works with, connects to, or is derived from TalkQTE, for example "works with TalkQTE" or "a fork of TalkQTE".
- Running or sharing an unmodified copy under the project license with its name and icons intact.
- Keeping the name and icons in a modified copy you run yourself, or in a fork you use to prepare contributions to this project, as long as you do not share builds of it with others.

## Uses that need permission

- Naming a modified version or fork that you share with others, or a product, service, company, or domain, "TalkQTE" or something confusingly similar.
- Using the logo or app icons for a modified version that you share with others, or for another product or service.
- Presenting your work in a way that suggests it comes from, is endorsed by, or is supported by this project when it is not.

If you share a modified version, give it a different name and icon. You may say that it is based on TalkQTE. Renaming applies to the product name and icons, not to the license or copyright notices: the project license separately requires that you keep the licensor's licensing, copyright, and other notices intact, pass on a copy of the license terms, and include a prominent notice that you modified the software.

## Asking for permission

Open a [name and logo inquiry](https://github.com/connorburgess/talkqte/issues/new?title=Name%20and%20logo%20inquiry) requesting a private contact. Keep confidential business details out of public issues. An inquiry does not grant permission.

Permission to use the name or logo is separate from a commercial software agreement, described in the [licensing guide](LICENSING.md).
